Developer Portfolio 

Det här är min portfolio som jag har byggt med HTML och CSS utifrån en färdig designskiss i Figma. 

Publicerad sida 

Länk till sidan: https://alperen-tech.github.io/developer-portfolio/

Reflektion 

Från skiss till kod 

Jag började med att titta på designen i Figma och försökte dela upp sidan i mindre delar. Jag såg att alla sidor hade ungefär samma header och navigation, men olika innehåll. 

Jag började därför med startsidan och skapade först header, navigation och hero-sektionen. Efter det byggde jag About, Tech Stack, Projects och Contact som egna HTML-sidor. 

Det som var svårast var att få avstånd, textstorlekar och placeringar att likna designen. Jag behövde testa flera olika värden i CSS. På startsidan använde jag till exempel Flexbox för att placera texten och profilbilden bredvid varandra på desktop. 

Semantik 

Jag försökte använda semantiska HTML-element där det passade. 

Jag använde: 

header för sidans header 

nav för navigationen 

main för huvudinnehållet 

section för olika sektioner 

article för projekt, jobb och utbildningar 

footer för sidfoten 

Jag använde också några div-element. Till exempel använder jag div för containers och för att gruppera innehåll som behöver stylas med Flexbox. Där tyckte jag inte att det fanns något bättre semantiskt HTML-element. 

Layout 

Jag valde att använda Flexbox i projektet. 

I headern använder jag Flexbox för att placera logotypen och navigationen. På startsidan använder jag Flexbox för texten och profilbilden. 

Jag använder också Flexbox på Tech Stack-sidan för att placera teknikikonerna och på Projects-sidan för att placera projektkorten. 

Sidan är byggd mobile first. Det betyder att CSS-reglerna först är skrivna för mindre skärmar. Sedan använder jag media queries med min-width. 

Min huvudsakliga brytpunkt är 768px. Där ändras flera delar från mobil layout till desktop layout. 

Tillgänglighet 

Jag har försökt göra sidan tillgänglig genom att använda semantisk HTML och vanliga länkar för navigationen. 

Bilderna har alt-text som beskriver innehållet. Navigationen har också en aria-label. 

Jag har lagt till :focus-visible i CSS så att det syns tydligt vilken länk som är markerad när man använder tangentbordet. 

Jag har också försökt använda tydliga färger och bra kontrast mellan text och bakgrund. 

Jag ska även testa sidan med Tab-tangenten och kontrollera HTML-koden i W3C Validator innan inlämning. 

Användbarhet 

Designen använder samma navigation på alla sidor. Det gör att användaren lätt kan förstå hur man går mellan sidorna. 

Designen använder också tydliga rubriker och mycket tomrum mellan olika delar. Det gör innehållet lättare att läsa. 

På Projects-sidan används kort med samma struktur. Det gör det lätt att se vilka delar som hör ihop. 

Om jag hade gjort designen själv hade jag kanske gjort vissa länkar lite större för att de skulle vara enklare att klicka på. 

Styrkor och brister 

Jag tycker att det blev bra att sidan fungerar både på mobil och desktop. 

Jag tycker också att Flexbox gjorde det enklare att placera innehållet på olika sätt beroende på skärmstorlek. 

Om jag hade haft mer tid hade jag försökt få alla avstånd och storlekar ännu närmare Figma-designen. Jag hade också lagt in fler riktiga projektbilder och riktiga länkar till mina projekt. 

AI-verktyg 

Jag använde ChatGPT som stöd under uppgiften. 

Jag använde det för att få hjälp med responsiv design och förslag på CSS. Jag använde också AI som stöd när jag skrev min README och reflektion.
